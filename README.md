# HACKATON API SENTIMIENTOS - TESTING

## Entorno virtual Python

### Crear entorno virtual Python

```bash
python -m venv venv
```

### Activar el entorno virtual

```bash
venv\Scripts\activate
```

### Instalacion de paquetes

```bash
pip install -r requirements.txt
```
